# pairwise-decal-projection

墙面弹孔贴花在斜视角下变成一条拉伸的条纹，换到角色身上又整片悬空：贴花按世界坐标投影，没有沿表面法线做深度重建；法线混合只做加法，粗糙墙面上的弹孔高光反了；深度偏移固定，斜坡和曲面处出现 Z-fighting；贴花图集按 UV 直接采样，边缘没有 clamp 到透明，邻格颜色渗进来；贴花投到蒙皮网格时用绑定姿势位置，角色一动就漂移；贴花生命周期按帧数，场景暂停后永久不消失；多相机各自渲染一份贴花，分屏边缘重复叠加；HDR 贴花颜色没做色调映射，亮部烧成白块；掠射角没有淡出，贴花在墙边缘拉成长条；贴花被几何体裁掉一半，模板缓冲没处理交叠；透明贴花和玻璃排序错乱，互相吞；实例化贴花的变换矩阵在批次间共享，旋转后全部错位；贴花缓存按材质 ID，换贴图后仍用旧图。render/decal_projection.py 是核心，tests/test_decal_projection.py 15个红。要修的是：深度重建；法线混合；动态偏移；图集边界；蒙皮位置；生命周期；多相机去重；HDR 映射；掠射淡出；模板裁剪；透明排序；实例变换；缓存版本。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
